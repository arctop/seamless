Seamless for the Claude app

The tenth chat about a deal should know what the first nine decided.

Seamless gives Claude in the desktop app a record of your work that lives on your own computer. As you go, Claude saves each rule and decision as a plain file, with the date it was made and what it replaced. The next chat reads the record before it answers.

ii. what changes

What a chat gets when it starts from the record.

  • It’s briefed before the first answer.

    Name the project, or let a Claude Project’s instructions name it, and Claude loads the project’s rules and latest decisions before it replies.

  • Decisions keep their history.

    A changed position is saved as a replacement. The old entry stays readable, marked with what replaced it and when, so “what did we agree before September 12?” has an answer.

  • Clients stay apart.

    Make a project confidential and chats about your other work can’t read it. Make it sealed and nothing from outside gets in either. You can still see everything yourself.

  • Open items outlast the chat.

    To-dos live in the project, in order when one waits on another, until someone closes them.

  • The record is a folder you can open.

    Rules, decisions, and notes are plain text files on your computer. Read them in any text editor, search them, and back them up with everything else.

  • Your other AI tools read it too.

    Claude Code, Codex, and other apps that connect to MCP servers read and write the same projects, so a decision made in a chat reaches the agent doing the work.

iii. next to Claude’s memory

Claude already remembers some things. Here’s where Seamless differs.

Claude’s apps have a memory of their own, on by default for individual plans. Claude generates it from your chats as entries grouped by topic, keeps a separate one for each Claude Project, and lets you read, edit, and delete what it holds. For a lot of people that’s enough. The two sit side by side without conflict: Claude’s memory carries the general picture of you and your work, and Seamless holds the record a matter needs.

iv. your files

Every entry is a file on your own computer.

Seamless is a small program that runs in the background. It has no account and no cloud, sends no usage data, and only answers your own machine. This is the entry Harbor’s chat replaced today, still on disk and marked with what replaced it.

  • Your chats still go to Anthropic. When Claude reads an entry into a conversation, that text becomes part of the chat and is handled like everything else you type, under your Claude plan’s terms. Seamless doesn’t change what Anthropic receives or keeps.
  • Search stays on your machine unless you change it. Out of the box, search is keyword-only and offline. Search by meaning is optional: with an OpenAI key, the text of your entries is sent to OpenAI to be indexed; with Ollama, it stays on your computer.
  • The walls are between conversations. A sealed project keeps one client’s record out of another client’s chats. It isn’t a lock: anyone who can sign in to your computer account can open the folder.
  • No compliance claims. Whether this setup fits your professional obligations is a judgment for you, or for your firm.

v. set it up

About ten minutes, once.

You need the Claude desktop app for Mac or Windows, and a few minutes in the terminal. Everything after that happens in Claude.

  1. 1Open the terminal

    Press ⌘-Space, type Terminal, and press Return.

    Open the Start menu, type PowerShell, and press Enter.

  2. 2Paste this, then press Return

    Mac

    $curl -fsSL https://thereisnospoon.org/install | sh

    Windows

    PS>irm https://thereisnospoon.org/install.ps1 | iex

    what it prints, abridged (Mac)

    checksum ok

    warning: cosign not found -- archive verified by checksum only.

    installed /Users/you/.local/bin/seamlessd, /Users/you/.local/bin/seam

    …

    service com.arctop.seamless (launchd)

    healthz ok -- http://127.0.0.1:8081/healthz

    …

    chat in the Claude app -- the seamless MCP tools load after an app restart

    what it prints, abridged (Windows)

    checksum ok

    WARNING: cosign not found -- archive verified by checksum only.

    installed C:\Users\you\.local\bin\seamlessd.exe, C:\Users\you\.local\bin\seam.exe

    …

    service Seamless (Scheduled Task, at logon)

    healthz ok -- http://127.0.0.1:8081/healthz

    …

    chat in the Claude app -- the seamless MCP tools load after an app restart

    It checks the download against its published checksum, installs Seamless for your user only, starts it in the background, and connects the Claude app. If it also finds Claude Code or Codex, it asks which to connect; pressing Return keeps what it found.

    Two lines that look like problems, and aren’t

    The cosign warning means an optional signing tool isn’t installed; the download still matched its published checksum. On a Mac it may also suggest adding a folder to your PATH, which the Claude app doesn’t need. The installer is one readable script (PowerShell), if you’d like to look first.

  3. 3Quit Claude and open it again

    Claude loads its connections when it starts. Quit it completely, not just its window, then reopen it.

  4. 4Start your first project

    In a new chat, ask in plain words:

    in a chatCreate a sealed Seamless project called Harbor acquisition, then start a Seamless session in it.

    When Claude first reaches for a Seamless tool, the app asks for your approval; allow it once or always. From then on, tell Claude what to keep as you work: “save that as a decision”, or “that’s a rule for this client”. More to say is just below.

  5. 5Make every chat start from the record optional

    A chat doesn’t load the record by itself. If you keep this work in a Claude Project, add a line to the Project’s instructions so that each chat in it starts by loading the record:

    instructionsAt the start of every chat, call the Seamless session_start tool with project harbor-acquisition and read the briefing before answering. When we settle a rule or a decision, save it to Seamless, and when a decision changes, save the new one as superseding the old.

  6. 6Read what’s been saved optional

    Ask Claude what Seamless has on a project, or open the console, a private page in your browser that lists every project, entry, and open item. Run this in the terminal:

    Mac

    $~/.local/bin/seamlessd console-open

    Windows, in a new PowerShell window

    PS>seamlessd console-open

    Or open the folder itself: in the Finder, press ⌘-Shift-G and paste ~/.seamless/memory.

changed your mind?

Leaving takes one command.

Mac

$~/.local/bin/seamlessd uninstall --dry-run

Windows

PS>seamlessd uninstall --dry-run

Prints exactly what would be removed, and removes nothing. Drop --dry-run to do it.

  • Stops and removes the background program
  • Disconnects the Claude app and leaves its other settings alone
  • Deletes Seamless itself. Running it twice is harmless.

Your entries stay in ~/.seamless, because removing a program shouldn’t delete your work. Add --purge to remove them too.

vi. first chats

What to say in your first few chats.

Plain requests, typed into a chat in the Claude desktop app. Copy one, swap in the name of your own matter, and see what Claude saves. The replies are illustrations, and the tools Claude calls in them are real.

Load a project

in a chatLoad my Harbor acquisition project from Seamless.

A chat starts blank until you ask. Put the instruction from step 5 in a Claude Project and every chat in it does this on its own.

Keep a rule

in a chatSave this to Harbor as a rule: drafts go to the other side as PDFs, never as Word files.

Call it a rule when it holds no matter what, and a decision when it might change later. Either way it’s one plain file, with the date it was saved.

Save a note

in a chatSave a summary of this call as a note in Harbor, dated today.

Notes are for the long version: a call, a memo, a page of research. Rules and decisions stay short, as entries of their own. Ask about the board later and Claude finds both.

Plan with tasks

in a chatMake a plan for closing Harbor, with tasks in order: the KYC list, then the disclosure schedule, then the signing call.

Then, in any chat later on:

in a chatWhat is next on Harbor?

Open items stay in the project, in order, until someone closes them, however many chats later.

Bring in past chats

in a chatSearch my past chats about Harbor and list the decisions we made, with dates. Then save the ones I pick to Seamless.

Searching past chats is Claude’s own feature, and it only works when it’s turned on in Claude’s settings. Without it, paste an old conversation into the chat and ask the same thing.

Ask what changed

in a chatWhat was the indemnity cap before it changed, and when did it change?

A replaced entry drops out of briefings and search, and stays on disk with what replaced it and when. That’s why the question still has an answer.

Wrap up

in a chatBefore I go, save where we left off on Harbor.

Next time, “Load my Harbor acquisition project” brings this summary back with everything else.

fair questions

What it doesn’t do.

Short answers, including the ones that might rule it out for you. The technical setup guide has the rest.

Does it work on claude.ai or on my phone?

No. Seamless runs on your computer and connects through a setting that only the Claude desktop app reads, so Claude on the web, the phone apps, and Cowork tasks can’t reach it.

Will Claude load my project on its own?

Not in a chat. Claude Code gets a briefing automatically at the start of every session, but a chat has no such hook. Claude loads a project when you ask, or when a Claude Project’s instructions tell it to (step 5 above).

Does it read my documents or my email?

No. It keeps what you and Claude decide to write down, plus any web page you ask it to capture. Contracts and decks still belong in a Claude Project, a document system, or a folder.

Can my team share it?

It’s set up for one person on one computer. A trusted team can share one copy over a network, but there are no per-person permissions: everyone with access sees everything.

Does it work on Windows?

It should. The Windows app is wired the same way and the installer handles it, but the chat connection has only been checked end to end on a Mac so far. If you try it on Windows, tell us how it went.

Do I have to use the terminal?

Twice: once to install, and once if you remove it. Everything in between happens in Claude, and reading the files yourself is optional.

What does it cost?

Nothing. Seamless is free and open source under the MIT license, and there’s no account to create.
