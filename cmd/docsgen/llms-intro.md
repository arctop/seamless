Seamless is a free, open-source (MIT) tool that gives the AI coding agents you run one shared memory and one task queue, kept on your own computer. It works with Claude Code, Codex (CLI, desktop app and IDE extension), the Claude desktop app, and any other MCP client, on macOS, Linux and Windows. It is published by Arctop.

**The problem it solves.** Knowledge gets lost wherever work passes from one agent to the next. A new session knows what the last one worked out only if someone wrote it down, so you explain a decision again or watch the agent undo it. Agents working side by side cannot see what the others found or which task is taken, so you relay between them. Claude Code and Codex each keep their own notes, so what one learned the other never sees. Today the person running the agents carries that context across by hand.

**How it works.** Agents save what they learn (constraints, decisions, gotchas, runbooks) as one markdown file each under `~/.seamless`. A hook briefs every new Claude Code or Codex session from those files before its first prompt, and matches each later prompt against them. Parallel agents claim steps from one dependency-aware queue, and a claim is atomic and leased, so two agents never hold the same step. A gardener proposes merges and retirements; nothing is merged, retired or forgotten until you approve it.

**How it differs from built-in memory.** Claude Code's auto memory is notes that one client keeps for itself, per repository, on one computer, and it is not loaded into subagents. Seamless is one store that every session, subagent and client reads and writes, with tasks and plans beside it. The two run side by side, and so does your `CLAUDE.md` or `AGENTS.md`: those files hold the instructions you wrote, and Seamless holds what the agents learn as they work.

**What it costs to try.** One command installs a small local daemon and wires the agents it finds: `curl -fsSL https://thereisnospoon.org/install | sh` on macOS or Linux, `irm https://thereisnospoon.org/install.ps1 | iex` on Windows. There is no account and no telemetry. `seamlessd uninstall` removes it and leaves your files where they are.
